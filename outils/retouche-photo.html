Préparer une photo

Choisis une photo, recadre-la, redimensionne-la et télécharge le résultat prêt à l'emploi. Tout se passe directement dans ton navigateur : aucune photo n'est envoyée nulle part.

Après le téléchargement, il reste deux gestes pour que la photo apparaisse sur le site :
  1. Dépose le fichier téléchargé dans le dossier images/ de ton dépôt GitHub (glisser-déposer, comme d'habitude).
  2. Colle le nom de ce fichier dans la colonne ImageURL de la ligne correspondante dans ton Google Sheet, par exemple images/chimay-bleue.jpg.

Glisse une photo ici, ou clique pour en choisir une sur ton appareil.
